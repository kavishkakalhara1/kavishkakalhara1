## 🚀 Featured Projects

### 🔐 AI-Driven Self-Healing Security Framework for Resilient IoT Systems
*Final Year Project · Paper submitted to IEEE BuildSEC'26*

A two-tier IoT security framework trained on CICIIoT 2025: **edge anomaly detection (99.6% accuracy, 0.997 F1)** and **cloud attack classification (94.6% accuracy)**. Remediation is automated with SHAP-guided playbooks, with RAG-grounded LLM agents handling fallback decisions and operator escalation.

`FastAPI` `LangChain` `FAISS` `GRU Autoencoder` `Deep SVDD` `XGBoost` `SHAP` `WebSockets`

### 🏗️ Engineering ERP: Full-Stack Microservices Platform
A construction ERP covering project planning, BOQ estimation, workforce management, site attendance, and accounting. Includes MFA, approval workflows, audit trails, and encrypted offline mobile reports.

`Spring Boot` `PostgreSQL` `React` `React Native` `Keycloak` `Kafka` `Docker` `Playwright` `GitHub Actions`

### 🎓 refaa.lk: Alumni Platform
A production platform serving 1,000+ alumni with role-based access, payments, analytics, and a horizontally scaled backend.

`React` `Node.js` `Express` `MongoDB` `Redis` `Kafka` `AWS EC2` `Nginx` `Cloudflare`
